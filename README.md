# Smart Study Pro — LevelUp

A student productivity dashboard designed to help students track goals, assignments, focused study time, and learning consistency in one place.

## Features

- **Dashboard:** Quick overview of goals, completed tasks, focus time, and learning streak.
- **Goal tracker:** Add goals, define steps, track progress, and remove goals.
- **Task manager:** Add assignments, set a subject, due date, and priority, then mark tasks complete or delete them.
- **Focus timer:** Run a 25-minute study session and record the session.
- **Progress dashboard:** View weekly study activity and session history.
- **Learning streak:** Track study days with a calendar and milestone progress.
- **Local storage:** Your changes are saved in the browser on the device you use.
- **Responsive design:** Layout adapts to desktop and mobile screens.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser such as Chrome or Edge.
3. Start adding your goals and tasks.

No build tools or package installation are required.

## Data note

The app uses browser `localStorage`. Data is stored locally in the current browser and is not automatically synced across devices or browsers. Clearing browser storage may remove saved progress.
